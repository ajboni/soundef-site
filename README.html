Soundef Website — Hybrid C MVP1 (VitePress, D-023) ​

LANDING.md at repo root IS website/index.md verbatim (no duplication, per PLAN §2 Hybrid C, D-013 + D-023 VitePress).

  • website/index.md is generated by node ./scripts/sync-landing.js (also prebuild).
  • website/.vitepress/config.js is defineConfig consuming LANDING.md as index.md + ../docs/*.md synced to website/docs/*.md (no duplication).
  • website/dist/ is vitepress build → website/.vitepress/dist + public/schemas/soundef.v0.json (via scripts/build.js sync).
  • Dev: npm run site → vitepress dev --port 4173 with HMR; npm --prefix website run dev same.

CI guards: npm run lint:landing checks website/index.md === LANDING.md hash; website build runs in CI after lint:tasks.
